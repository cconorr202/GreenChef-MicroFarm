# GreenChef MicroFarm — сайт для GitHub Pages

Статичний багатосторінковий сайт українською мовою для демонстрації бізнес-ідеї GreenChef MicroFarm.

## Сторінки

- `index.html` — головна сторінка та ціннісна пропозиція.
- `catalog.html` — 9 культур, демонстраційні B2B-ціни та фільтри асортименту.
- `restaurants.html` — пропозиція для HoReCa, тестовий набір і форма заявки.
- `about.html` — концепція ферми, виробничий підхід і принципи роботи.
- `contacts.html` — демонстраційні контакти та FAQ.

## Публікація через GitHub Pages

1. Створіть новий репозиторій на GitHub.
2. Завантажте **весь вміст цієї папки** в корінь репозиторію. Файл `index.html` має лежати в корені, а не у вкладеній папці.
3. Відкрийте **Settings → Pages**.
4. У розділі **Build and deployment** виберіть **Deploy from a branch**.
5. Вкажіть гілку `main` і папку `/ (root)`, натисніть **Save**.
6. Після публікації GitHub покаже адресу сайту в цьому ж розділі.

Збірка, Node.js або сервер не потрібні. Файл `.nojekyll` додано для коректної публікації статичних ресурсів.

## Перед реальною публікацією

У цій версії контакти й отримувач форми є демонстраційними.

1. У `assets/js/main.js` замініть `ORDER_EMAIL = 'orders@greenchef.example'` на реальну адресу для заявок. Домен `.example` зарезервований для прикладів і не приймає пошту.
2. У `contacts.html` замініть телефон, email та Telegram на справжні контакти. Позначення «демо» після цього можна прибрати.
3. Перевірте актуальність цін, асортименту, умов доставки та можливості надання тестового набору.
4. Усі сторінки мають авторський підпис у підвалі: **«Розроблено Блонським Давидом · davjdbl777@gmail.com»**.

## Як працює форма замовлення

Сайт розміщується на GitHub Pages і не має власного backend. Після заповнення форми браузер перевіряє обов'язкові поля та формує лист `mailto:` з усіма даними заявки. Користувач має відкрити поштову програму та самостійно надіслати лист.

Форма **не зберігає** заявки на сервері та не надсилає їх автоматично. Для автоматичного приймання заявок потрібен зовнішній form-сервіс або окремий backend.

## Локальний перегляд

Можна відкрити `index.html` у браузері. Для тестування через локальний вебсервер (необов'язково) виконайте в цій папці:

```bash
python -m http.server 8000
```

Потім відкрийте `http://localhost:8000`.

## Примітка щодо змісту

Сайт спирається на бізнес-план GreenChef MicroFarm. Це презентація бізнес-концепції, а не підтвердження того, що ферма вже працює. Цінові значення відтворюють стартові орієнтири з бізнес-плану: 55 грн за 50 г для стандартних позицій і 65–75 грн за 50 г для преміальних. Остаточні ціни потрібно підтвердити перед комерційним використанням.
